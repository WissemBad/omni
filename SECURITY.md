# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Do not open a public issue. Use [private vulnerability reporting](https://github.com/WissemBad/omni/security/advisories/new) or write to contact@wissem.pro, with the version, the steps to reproduce and, if you can, a file that triggers the problem.

omni parses files from game archives, so a crash or memory issue in a parser counts. You will get an answer within a week.
